# R_Visionary V5.3
A public-ready static GCSE revision planner. No personal details or school timetable are built in. Upload index.html, style.css, app.js, studio.js and README.md to the root of your GitHub repository. Enable Settings > Pages > Deploy from a branch > main > / (root).

New users can add topics and new subjects directly in Topics, and edit exam boards, specifications and tiers in Settings, then enter their own timetable and revision availability (all days initially rest days). Preferences control session length, breaks, maximum topic sessions and colour accent. The past-paper page links to official board finders and a small set of verified subject resources; students can bookmark individual public HTTPS papers and mark schemes and record scores. It does not host exam PDFs or bypass restricted papers.

Progress is stored in localStorage on this browser and website origin. Export backups before switching devices or updating. Never commit personal backups to GitHub. Existing v1 local data is retained on the same website origin. The optional AI lab loads WebLLM and a local model in compatible WebGPU browsers; AI can make mistakes and is not required for the planner.

V3: Type any study level, choose exact whole-minute session and break lengths (within a single day), and set a daily automatic session limit. Overview lets you select a date, add any topic/coursework at an exact time, edit or remove individual sessions, or start a blank manual plan. Manual dates are preserved across automatic setting changes. Generate automatic plan explicitly to replace unfinished manual sessions. Existing data on the same origin and v2 backups remain compatible.

V4: Resource studio imports text from PDF, DOCX, PPTX, XLSX, CSV, TSV, TXT, Markdown, flashcard JSON and exported resource library JSON. Two-column CSV/TSV files are treated as question/answer pairs; XLSX decks should use Front/Back or Question/Answer column headers. The editor uses plain text and saves on demand. Flashcards and quizzes use one question || answer per line, and can be practised, exported as CSV, or printed. Slides are text outlines, not editable PowerPoint files. Original documents, images, diagrams, scanned PDFs, layouts and audio are not retained. Files are parsed on-device; third-party parsers are downloaded when needed. Limit: 15 MB per file, 120,000 extracted characters per resource, 200 resources (browser storage may fill sooner), 150 PDF pages/slides, 5,000 spreadsheet rows per sheet. Export your library or full backup regularly. AI uses the same WebLLM model as AI study lab, generates separate editable drafts, and accepts up to 2,400 source characters per request. AI is optional, imperfect and not independently moderated; a prompt is not a reliable safety filter. Do not treat generated study resources as verified facts. Use original or permitted study materials; never upload private school or student information to the public GitHub repository. All resource text is saved on the local browser, not in the repository.

Compatibility mode uses FP32 models that do not require shader-f16; these may require more memory. AI generation failures invalidate the engine and allow reloading. Unload / change model releases the current engine. Full GPU compatibility cannot be guaranteed. Local data storage key unchanged.

## V5.1 — browser-managed AI and offline resources
The previous WebLLM engine is replaced with Gemini Nano via Chrome’s built-in LanguageModel API. It requires supported desktop Chrome (148+ for the web Prompt API), hardware and disk space. Chrome manages the model and initial download. No API keys, WebLLM shaders, or external AI server. If the browser does not expose LanguageModel, AI is unavailable; use the offline tools instead. Browser availability and actual model performance depend on the device. Each generation uses a separate session; AI flashcards/quizzes use constrained JSON converted into editable question/answer lines. The site sends no profile name or timetable to the model. AI is optional and output is not independently moderated or verified. Keep use educational, check facts and do not enter private data.
The Resource Studio can create cards, cloze questions, notes and slide outlines from existing text without an AI download. Offline output is rule-based, not semantic AI, and may produce fewer cards than requested. The Study Lab includes a generic revision checklist without AI. Imports, original editor text and saved library remain separate from drafts. Same localStorage key and six files as V5. Back up your local data before updating.

## V5.2 — question generator reliability
Structured AI output is generated in small batches, validated, and deduplicated. Blank, numeric-only and placeholder questions are discarded; numerical answers remain valid. A partial result is labelled instead of padded with fake questions. Study Lab displays questions and collapsible answers separately; exported editor content remains compatible with Resource Studio. This is structural validation, not a check of factual accuracy or curriculum relevance. Real Gemini Nano availability depends on your browser and device.

## V5.3 — quizzes from your materials
Open or import a resource in Resource Studio, then scroll to Quiz builder. Choose the current editor (or selected passage) or an existing editable generated draft, 1–40 questions, and typed or multiple-choice format. The offline builder uses explicit question/answer pairs, definitions and cloze questions drawn from the supplied text. It may create fewer than requested, and multiple choice falls back to typed responses when fewer than four distinct source answers are available. Distractors are other source answers, not independently fact-checked alternatives. Review the question and expected answer; equivalent typed answers can be self-marked. Results show the score, source wording and missed questions, with retry and restart. Save questions separately to the resource library; current attempt scores are session-only. No AI or API key required. Optional AI draft generation (1–20) uses the existing browser-managed Gemini Nano, checks that answer text occurs in the source and requires review before starting; this is not semantic validation. Original source text stays unchanged. Same six website files and same local storage key. Scanned documents still need manual transcription.

## V5.4 — independent Quizzes and exam practice

- Quizzes is a separate navigation page. Paste text or drop a file directly into its source box, optionally choose a saved resource, or transfer a Resource Studio item with Create a quiz. Nothing is added to your resource library unless you explicitly save it.
- Past papers: save an official public paper/mark-scheme link, then click Practise this paper. Open the original PDF or attempt a direct HTTPS PDF import; cross-origin restrictions (CORS), logins, catalogue pages and restricted files are not bypassed. Download a permitted PDF yourself and upload it if direct import fails. Imports extract text only; scanned PDFs, diagrams and complex layouts may need manual transcription. Source and mark scheme are separate boxes. Highlight the relevant excerpt in either box to work on part of a paper.
- Study notes mode works offline with notes, definitions and explicit question || answer pairs. Exam question practice mode offline uses only user-provided question || answer pairs (one per line). For other paper excerpts, the optional browser AI drafts original questions informed by the supplied source and mark scheme; review and edit each draft before starting. No automatic matching of arbitrary official exam questions to mark schemes or official marking is claimed.
- New exam-style variations mode works offline for recognised linear equations (ax + b = c) and nonsingular simultaneous linear equations (ax + by = c). It keeps the coefficient pattern, varies solutions and calculates new right-hand sides, avoiding the original and duplicate questions; fewer questions may be produced. Other styles use the optional Gemini Nano draft. Original practice questions are not official exams, and AI-generated answers need checking. No official papers are bundled.
- Both modes support typed answers, multiple choice where sufficiently distinct options exist, retries, and saving question/answer pairs. Automatically checked maths variants accept common integer solution notation. Quiz attempts are in memory until a new attempt or page reload. Existing revision data and local storage keys are retained.
- For AI, use a supported browser/device and check the status shown in Quizzes. Source materials remain in the browser (document parser libraries may download from their existing CDNs). Direct URL import contacts the file host, without credentials. No API key or proxy is required.
